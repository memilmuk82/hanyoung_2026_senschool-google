## 1. 연수의 핵심 흐름

이번 연수는 기능 목록을 나열하는 방식보다, 교사가 실제 자료를 읽고 검토해 수업 준비로 연결하는 과정을 중심으로 구성했습니다.

> **Source → Prompt → Verify → Output**  
> 자료를 고르고 → 질문하고 → 근거를 확인하고 → 필요한 산출물로 만듭니다.

주요 내용은 다음과 같습니다.

1. **SEN스쿨**
   - 2026학년도 2학기 주요 개편

   - 교과서 출판사 연계
2. **Google Workspace for Education / Education Plus**
   - Google 교육 환경의 전체 구조
   - 이번 연수에서 활용하는 주요 AI 기능의 위치
3. **한영고 콰렌스 콜로키움 사례**
   - QBL 기반 탐구 맥락
   - Big Question: `생성형 AI 시대에 학생의 능력을 우리는 무엇으로 평가해야 하는가?`
4. **Gemini Notebook**
   - Source / Chat / Studio
   - 실제 8개 Source를 활용한 강사 시연
   - Prompt 작성과 인용 확인
   - 실제 오류 사례를 통한 Verify
   - Studio의 인포그래픽·마인드맵·슬라이드·퀴즈 결과 검토
5. **Classroom Gemini**
   - `일반적인 오개념 바로잡기`
   - 실제 생성 결과 검토와 수정
   - 참가자 현장 실습
6. **SenGPT**
   - 모델 선택과 사용량 확인
   - 서울시교육청 에이전트

## 3. 실행 방법

### 가장 간단한 방법

압축을 해제한 뒤 루트의 `index.html`을 엽니다.

시작 화면에서 다음 두 항목을 선택할 수 있습니다.

- **발표자료 열기**
- **참가자 교재 열기**

### 로컬 웹 서버로 실행하기 — 권장

브라우저의 로컬 파일 정책에 영향을 받지 않도록 간단한 로컬 서버로 실행할 수 있습니다.

```bash
cd hanyoung-2026
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열면 됩니다.

인터넷 연결이 필요한 외부 서비스 링크와 실제 실습을 제외하면, 발표 웹앱 자체는 패키지의 로컬 파일을 사용합니다.

## 4. 발표자료 조작법

| 조작 | 기능 |
|---|---|
| `→`, `PageDown`, `Space` | 다음 단계 또는 다음 슬라이드 |
| `←`, `PageUp` | 이전 단계 또는 이전 슬라이드 |
| `Home` | 첫 슬라이드 |
| `End` | 마지막 슬라이드 |
| `O` | 전체 슬라이드 개요 |
| `N` | 강사 노트 열기/닫기 |
| `F` | 전체화면 |
| `P` | PDF/인쇄 |
| `Esc` | 열린 팝업·개요·노트 닫기 |

일부 SEN 절차 화면은 한 슬라이드 안에서 **번호와 설명이 순서대로 나타나는 단계형 화면**으로 구성되어 있습니다.

수업지원 ToolKit과 일부 실제 화면 카드는 **클릭·Enter·터치**로 확대할 수 있습니다. 팝업이 열린 동안에는 슬라이드 이동 키가 우선 동작하지 않도록 구성했습니다.

## 8. 자료 해석 원칙

이 연수에서는 AI 생성 결과를 바로 정답이나 학교의 공식 기준으로 사용하지 않습니다.

특히 다음을 확인합니다.

- 인용 번호가 있다는 사실과, 인용이 실제 주장을 뒷받침한다는 사실은 다릅니다.
- `~될 수 있음`과 같은 가능 표현을 `~해야 함`으로 강화하지 않았는지 확인합니다.
- 특정 연구 결과를 모든 교과·모든 학생에게 일반화하지 않습니다.
- 학교 프로그램의 운영 방향과 교과 수행평가 기준을 혼합하지 않습니다.
- 개인정보 보호 안내를 학생 능력의 평가 기준으로 바꾸지 않습니다.
- 최종 채택·수정·적용은 교사가 판단합니다.

## 9. 화면과 기능의 기준 시점

서비스 화면은 주로 **2026년 9월 28~29일 실제 교육계정에서 확인한 UI**를 기준으로 구성했습니다.

Google Workspace, Classroom Gemini, Gemini Notebook, SEN스쿨, SenGPT 등 온라인 서비스는 이후 UI·기능·사용 한도가 변경될 수 있습니다. 연수 후 다시 사용할 때에는 현재 계정에서 보이는 메뉴와 공식 안내를 우선 확인해 주세요.

SenGPT 사용 가능량 역시 계정 유형과 시점에 따라 다를 수 있으므로 각자의 화면에서 현재 제공량과 초기화 시점을 확인하는 것을 권장합니다.

## 10. 배포 전 확인 사항

다른 학교·외부 연수에 이 패키지를 재사용하거나 공개 배포하기 전에는 다음을 다시 확인하는 것이 좋습니다.

- [ ] Padlet/교재 QR이 현재 주소로 연결되는가
- [ ] SEN·Google·SenGPT 화면이 현재 UI와 일치하는가
- [ ] 계정별로 사용할 수 있는 메뉴가 다른 부분은 없는가
- [ ] 실제 화면 캡처의 공개 범위가 적절한가
- [ ] 한영고 내부 자료가 외부 배포물에 포함되지 않았는가
- [ ] 링크된 공개 원문이 정상적으로 열리는가
- [ ] 참가자 교재와 발표자료의 상대경로가 깨지지 않았는가

## 11. 수정할 때 주의할 점

### 슬라이드 추가·수정

발표 내용은 `slides/slides.js`, 디자인은 `slides/styles.css`와 `slides/hanyoung.css`, 발표 동작은 `slides/app.js`에서 관리합니다.

### 교재 수정

참가자 교재 본문은 `guide/content.js`, 디자인은 `guide/guide.css`와 `guide/hanyoung-guide.css`에서 관리합니다.

### 이미지 교체

기존 상대경로를 유지하거나, 코드에서 참조하는 경로를 함께 수정해야 합니다. 특히 `assets/` 하위 폴더명을 임의로 변경하지 않는 것을 권장합니다.

## 12. 권장 발표 전 점검

연수 직전에 다음만 실제 발표 PC에서 확인하면 됩니다.

1. 루트 `index.html`이 정상적으로 열리는지
2. 전체화면(`F`) 진입이 되는지
3. QR 2개를 휴대전화로 직접 스캔할 수 있는지
4. ToolKit 카드 하나를 눌러 팝업이 열리는지
5. `O` 개요와 `N` 강사 노트가 정상 동작하는지
6. Classroom Gemini 실습 계정에 메뉴가 보이는지
7. SenGPT 로그인과 나만의 에이전트/예약 화면이 열리는지
8. 참가자 교재 링크가 정상적으로 이동하는지
